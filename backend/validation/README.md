# CodePilot Scoring Engine — Empirical Validation Harness

## Overview

This directory contains a reproducible benchmark harness for evaluating
CodePilot Scoring Engine v2.0. It is designed for academic validation
and is **separate** from the normal application test suite.

## Directory Structure

```
validation/
├── benchmark/
│   ├── sample01.py ... sample20.py    # 20 Python benchmark samples
│   ├── ground_truth.csv               # Independent ground-truth labels
│   └── model_properties/              # Synthetic cases for mathematical validation
│       ├── confidence_base.py
│       ├── severity_low.py / medium / high / critical
│       ├── size_500.py / 1000 / 2000
│       └── complexity_low.py / medium / high
├── scripts/
│   ├── run_validation.py              # Runs CodePilot pipeline on all benchmarks
│   └── analyze_results.py             # Analyzes results and validates properties
├── results/
│   ├── codepilot_results.csv          # Generated by run_validation.py
│   ├── analysis_summary.txt           # Generated by analyze_results.py
│   ├── ranked_by_overall.csv          # For external comparison
│   ├── ranked_by_security.csv
│   ├── ranked_by_maintainability.csv
│   └── VALIDATION_REPORT.md           # Report template
└── README.md                          # This file
```

## How to Run the Benchmark

### Prerequisites

- Python 3.10+
- The `backend/` directory must be the working directory
- No external dependencies beyond what CodePilot already requires
- **Gemini API key is NOT required** (AI analysis is skipped)

### Step 1: Run the Validation

```bash
cd backend
python -m validation.scripts.run_validation
```

This will:
1. Discover all `sample*.py` files in `validation/benchmark/`
2. Discover all `.py` files in `validation/benchmark/model_properties/`
3. Run each file through the REAL CodePilot pipeline:
   - `StaticAnalyzer.analyze(code, "Python")`
   - `StaticAnalyzer.calculate_cyclomatic_complexity(code)`
   - `HybridEngine.normalize()` + `HybridEngine.fuse()`
   - `ConfidenceEngine.calculate_all()`
   - `ScoringEngine.calculate_scores()`
4. Save results to `validation/results/codepilot_results.csv`

### Step 2: Analyze Results

```bash
cd backend
python -m validation.scripts.analyze_results
```

This will:
1. Load `codepilot_results.csv`
2. Validate mathematical properties (boundedness, monotonicity, etc.)
3. Compute descriptive statistics
4. Check group ordering (A > B > C > D > E)
5. Generate ranked CSVs for external comparison
6. Save summary to `validation/results/analysis_summary.txt`

### Expected Output

- `codepilot_results.csv`: One row per benchmark file with all scores
- `analysis_summary.txt`: Mathematical validation results + statistics
- `ranked_by_overall.csv`: Files ranked by overall quality (ascending)
- `ranked_by_security.csv`: Files ranked by security score (ascending)
- `ranked_by_maintainability.csv`: Files ranked by maintainability score (ascending)

## Running Without Gemini

The validation runner **never calls Gemini**. All issues come from the static
analyzer only. The ConfidenceEngine assigns base confidence = 85 for
"Static"-source issues (the same value used in production when AI is unavailable).

This makes the experiment fully reproducible without an API key.

## How to Add Another Benchmark File

1. Create `validation/benchmark/sampleNN.py` (follow the naming convention)
2. Add a row to `validation/benchmark/ground_truth.csv` with:
   - Qualitative severity labels (`none`, `low`, `medium`, `high`, `critical`)
   - Document why you assigned each label
   - Set `ground_truth_source` to explain your reasoning
3. Re-run `run_validation.py` and `analyze_results.py`

## How Ground Truth is Recorded

Ground truth labels in `ground_truth.csv` are assigned **before** running CodePilot.
They reflect the **known characteristics** of each controlled benchmark sample.

Labels are **NOT derived from CodePilot's own scores**. They represent an
independent assessment of expected code quality.

## How to Reproduce from a Clean Checkout

```bash
git clone <repository>
cd Codepilot/backend
pip install -r requirements.txt     # if needed
python -m validation.scripts.run_validation
python -m validation.scripts.analyze_results
```

No database, Redis, or Gemini API key is required.

## Academic Integrity

- Ground truth labels were assigned before seeing CodePilot results
- No samples were removed after seeing inconvenient results
- No weights were tuned to improve benchmark performance
- No external tool results were fabricated
- No correlation coefficients were computed without actual data
- This harness produces an experiment, not a demonstration
