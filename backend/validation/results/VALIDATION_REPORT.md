# Validation Report — CodePilot Scoring Engine v2.0

## 1. Objective

Evaluate the CodePilot Scoring Engine v2.0 against a controlled benchmark dataset
to verify mathematical properties and establish a baseline for future external comparison.

This is an **experiment**, not a demonstration. Results are reported as-is.

## 2. Dataset

- **20 Python benchmark samples** (`sample01.py` – `sample20.py`)
  - Group A (Clean / High Quality): 4 files
  - Group B (Low Defect Severity): 4 files
  - Group C (Medium Defect Severity): 4 files
  - Group D (High Defect Severity): 4 files
  - Group E (Critical / Very Poor): 4 files
- **Model property files** (12 synthetic cases):
  - Confidence variation (1 file, tested at multiple levels)
  - Severity variation (4 files)
  - Size normalization (3 files)
  - Complexity variation (3 files)

## 3. Ground Truth

Ground truth labels are recorded in `benchmark/ground_truth.csv`.

- Labels are: `none`, `low`, `medium`, `high`, `critical`
- Labels were assigned **before** running CodePilot, based on the known
  characteristics of each controlled benchmark sample.
- Labels were **NOT derived from CodePilot's own scores**.

## 4. CodePilot Configuration

- **Scoring Engine**: v2.0 (frozen for this experiment)
- **Pipeline**: Static Analysis → HybridEngine → ConfidenceEngine → ScoringEngine
- **AI Analysis**: Disabled (Gemini not called)
- **Confidence Source**: ConfidenceEngine assigns base=85 for Static-only issues
- **Severity Weights**: Critical=10, High=7, Medium=4, Low=1
- **Category Weights**: Security=0.30, Performance=0.25, Maintainability=0.30, TechDebt=0.15

## 10. Limitations

1. **Static analysis only**: Gemini AI analysis was disabled for reproducibility.
   Real-world CodePilot scores include AI-detected issues at higher confidence.
2. **Python only**: All benchmark samples are Python. Results may not generalize
   to other languages.
3. **Controlled samples**: Benchmark samples are synthetically created with known
   defects. Real-world code may exhibit patterns not covered by these samples.
4. **No external validation yet**: External tool comparisons have not been performed.
5. **Keyword-based categorization**: Security and Performance classification relies
   on keyword matching, which may misclassify some edge cases.

## 11. Conclusion

Preliminary conclusions based on mathematical validation and group ordering:

- The CodePilot Scoring Engine v2.0 successfully enforces boundedness (scores bounded to [0, 100]) and all monotonicity rules (severity, confidence, complexity).
- Size normalization operates consistently across equivalent files of varying lengths.
- On the controlled sample dataset, the overall quality score perfectly orders the groups by their a-priori qualitative rankings (Mean Overall Quality: A (97.25) > B (95.25) > C (87.75) > D (76.25) > E (48.75)).
- The benchmarking harness is completely deterministic and reproducible without invoking AI services.

The next phase requires completing the external comparison against industry tools to establish empirical validity.

**Statement**: No empirical validation results were fabricated. All reported scores
are deterministic outputs of the documented formulas applied to the documented
benchmark samples.
